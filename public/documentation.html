Introduction

Welcome to the DXLeave API documentation. This API provides endpoints for managing leave requests, users, and other core data for the DXLeave application. All responses follow a consistent structure defined by our ResponseFormatter.

Base URL

https://your-domain.com

Authentication

Most endpoints require authentication using a Sanctum bearer token. Include it in the Authorization header.

Authorization: Bearer <your_sanctum_token>

Response Structure

The API returns JSON responses with a predictable structure for both successful and failed requests.

{
    "meta": {
        "code": 200,
        "status": "success",
        "message": "Operation was successful."
    },
    "data": { ... }
}
{
    "meta": {
        "code": 4xx/5xx,
        "status": "error",
        "message": "A specific error message."
    },
    "data": null
}

Authentication

Public endpoints for user registration, login, and password management.

POST/api/register

Creates a new user account. By default, the user is assigned the 'Employee' role and an annual leave entitlement is created.

Parameters

FieldTypeDescription
namestringRequired. The full name of the user.
employee_codestringRequired. Unique code for the employee.
emailstringRequired. A valid and unique email address.
passwordstringRequired. Minimum 8 characters.
password_confirmationstringRequired. Must match the password field.
department_idintegerOptional. The ID of the department the user belongs to.
manager_idintegerOptional. The ID of the user's manager.
hire_datedateOptional. The date the user was hired (YYYY-MM-DD).
POST/api/login

Authenticates a user and returns a Sanctum token.

Parameters

FieldTypeDescription
identifierstringRequired. Can be the user's email or employee_code.
passwordstringRequired. The user's password.
POST/api/logoutAuth Required

Invalidates the user's current Sanctum token, effectively logging them out.

POST/api/forgot-password

Sends a password reset token to the user's email if the user is found.

Parameters

FieldTypeDescription
identifierstringRequired. The user's email or employee_code.
POST/api/reset-password

Resets the user's password using the token sent to their email.

Parameters

FieldTypeDescription
emailstringRequired. The user's email address.
tokenstringRequired. The token received from the forgot-password step.
passwordstringRequired. The new password (min 8 characters).
password_confirmationstringRequired. Must match the new password.

User Profile

Endpoint for the authenticated user.

GET/api/userAuth Required

Fetches the profile of the authenticated user.

Leave Requests

Endpoints for employees to manage their own leave requests.

GET/api/leave-requestsAuth Required

Retrieves a list of the user's own leave requests. Managers with 'approve leave request' permission will see requests pending their approval.

POST/api/leave-requestsAuth Required

Submits a new leave request. The request is created with a 'Draft' status.

Parameters

FieldTypeDescription
leave_type_idintegerRequired. The ID of the leave type.
start_datedateRequired. Start date of the leave (YYYY-MM-DD).
end_datedateRequired. End date of the leave (YYYY-MM-DD).
reasonstringRequired. A brief reason for the leave.
PATCH/api/leave-requests/{id}Auth Required

Updates a leave request that is still in 'Draft' status. To submit for approval, change current_status to 'Pending'.

Parameters

FieldTypeDescription
leave_type_idintegerOptional.
start_datedateOptional.
end_datedateOptional.
reasonstringOptional.
current_statusstringOptional. Set to "Pending" to submit.

Approvals

Endpoints for managers to approve or reject leave requests.

PATCH/api/leave-requests/{id}/approveManager/Approver Role

Approves or rejects a pending leave request.

Parameters

FieldTypeDescription
actionstringRequired. Either "Approved" or "Rejected".
commentsstringOptional. Comments regarding the decision.

Admin: Master Data (CRUD)

Full CRUD endpoints for managing core system data. All are prefixed with /api/admin/master and require Super Admin role.

apiResource/usersSuper Admin

Manage users. Supports GET (list, with search & sort), POST, GET/{id}, PUT/PATCH/{id}, DELETE/{id}.

POST /users

FieldTypeDescription
namestringRequired.
employee_codestringRequired, unique.
emailstringRequired, unique, valid email.
passwordstringRequired, min 8 characters.
rolesarrayOptional. Array of role names.

PUT/PATCH /users/{id}

FieldTypeDescription
namestringOptional.
employee_codestringOptional, unique.
emailstringOptional, unique, valid email.
passwordstringOptional, min 8 characters.
rolesarrayOptional. Array of role names to sync.

POST & PUT/PATCH

FieldTypeDescription

POST & PUT/PATCH
