Introduction

Welcome to the DXLeave API documentation. This API provides endpoints for managing leave requests, users, and other core data for the DXLeave application. All responses follow a consistent structure defined by our ResponseFormatter.

Base URL

You can set your API's base URL in the input box in the left sidebar. It will be used to generate the code examples.

GET/api/leave-requestsAuth Required

Approvals

Endpoints for managers to approve or reject leave requests.

PATCH/api/leave-requests/{leaveRequest}/approveManager/Approver Role
