📋 Implementation Summary

Approver Roles: Super Admin, SL, SPV, ASMEN, TL, Manager

Supported Formats:

  • ✅ Array: ["Super Admin", "SL"] (from API)
  • ✅ String: "Super Admin,SL" (backward compatibility)

Function:

hasApproverRole() { const approverRoles = ['Super Admin', 'SL', 'SPV', 'ASMEN', 'TL', 'Manager']; let roles = []; if (Array.isArray(this.userRole)) { roles = this.userRole; } else if (typeof this.userRole === 'string' && this.userRole) { roles = this.userRole.split(',').map(r => r.trim()); } return roles.some(role => approverRoles.includes(role)); }
